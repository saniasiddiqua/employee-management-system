
# Employee Management System

## 📌 Project Overview

The Employee Management System is a SQL-based database project developed using MySQL.

This project manages employee information, departments, salaries, attendance, and performance records.

It demonstrates practical SQL skills such as database creation, table management, data insertion, joins, aggregate functions, and views.

## 🛠️ Technologies Used

- MySQL
- SQL
- MySQL Workbench
- GitHub

## 🗂️ Database Tables

The project includes the following tables:

1. Departments
2. Employees
3. Salaries
4. Attendance
5. Performance

## 💡 SQL Concepts Covered

- CREATE DATABASE

## 🔍 Project Features

- Store employee information
- Manage department details
- Track employee salaries
- Maintain attendance records
- Store performance reviews
- Generate employee reports using SQL queries

## ▶️ How to Use

1. Open MySQL Workbench.
2. Run `01_create_database.sql`.
3. Run `02_create_tables.sql`.
4. Run `03_insert_data.sql` if the database is empty.
5. Run the basic and advanced query files.
6. Run `06_views.sql` to create database views.
